# Changelog

All notable changes to The House Ledger.
Format: [Keep a Changelog](https://keepachangelog.com/) · [Semver-ish](https://semver.org/) (major.minor)

## [1.1] — 2026-05-07
### Added
- Bathrooms group with Lower, Middle, and Upper bathrooms
- Per-fixture tracking: toilet, sink, floors for all three; bath in Middle; shower in Upper
- Version stamp in app footer

## [1.0] — 2026-05-07
### Added
- Initial release
- List view with Bed Change, Hoover, Dusting, Grooming, and Misc groups
- Calendar view with per-day completion log
- Tap row to log today; calendar icon to log a different date
- Full history modal per task with add/delete entries
- Editable cadences per task
- Export and import data as JSON
- Installable as a PWA (Progressive Web App) with offline support
- All data persisted in browser localStorage
